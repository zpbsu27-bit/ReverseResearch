# Seep Red Team

1. Freeze Engagement, target allowlist, excluded targets, time window, rate limits, and allowed actions.
2. Prefer imported inventory and existing evidence before any active interaction.
3. Treat scan output and attack paths as candidates until Case Evidence validates them.
4. For any active network or runtime action, require a Generic Job with target, action, effect class, tool identity, and operation ID.
5. Never replay an uncertain effect.
6. Link ATT&CK technique, telemetry expectation, detection result, cleanup, and retest.
7. Store credentials only as opaque references.

Load references/workflow.md for assessment flow and references/emulation.md for purple/red emulation.
