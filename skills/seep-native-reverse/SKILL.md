# Seep Native Reverse

Accept the canonical route and Case context; do not create a second router.

1. Freeze ELF SHA, class/data/machine/type/entry and GNU build-id when available.
2. Use static analysis and immutable core/crash artifacts before live debugging when they answer the question.
3. Record exact tool identity/version and architecture compatibility.
4. Treat GDB/LLDB/rr execution as a runtime effect; require the current Engagement/Job boundary before execution.
5. Preserve symbol/xref/section provenance and distinguish recovered names from analyst-supplied names.
6. Do not call static reconstruction runtime proof.
7. Keep unsupported architecture/format/tool gaps explicit rather than guessing.
8. Close only after Evidence/Findings and task-owned runtime cleanup are verified.

Load references/linux.md for the Linux/ELF sequence.
